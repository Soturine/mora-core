# Cobertura da Documentação

## Estado

Este repositório foi criado como foundation `documentation-first` e cobre a visão discutida até o momento: ERP/PDV, SaaS, mobile, IA, sites, catálogo amplo, multi-tenancy, estoque, vendas, caixa, comissão, marketplaces, Bling, segurança, QA, DevSecOps, SRE/AIOps, performance, recovery e benchmark.

## Deliberadamente não finalizado

Os seguintes assuntos não podem ser considerados completos antes de discovery/implementação:
- política fiscal detalhada por CNPJ/operação;
- regras reais de comissão;
- modelo exato de pagamento/TEF;
- contratos reais de TikTok/Mercado Livre/Shopee;
- escolha de cloud/framework/ORM/auth/queue/storage;
- schema SQL final;
- OpenAPI real;
- SLO/RPO/RTO numéricos;
- preços/planos comerciais SaaS;
- política LGPD/termos jurídicos finais;
- UX/UI detalhada e design system;
- runbooks executáveis;
- CI/CD executável, pois ainda não há aplicação.

Esses itens estão **explicitamente incompletos por dependência de informação/evidência**, e não por falta de documentação acidental. Devem virar ADR/spec quando os requisitos forem resolvidos.
