# Visão do Produto

## Problema

Pequenos e médios varejistas frequentemente operam com sistemas separados para estoque, PDV, sites, marketplaces, fotos, atendimento, planilhas e relatórios. O mesmo produto é cadastrado várias vezes, o estoque diverge entre canais e tarefas simples dependem de múltiplos fornecedores.

## Visão

O Mora Core deve ser um **sistema operacional para o varejo físico e digital**, com uma fonte canônica de produto, estoque e operação.

```text
Mercadoria chega
→ identifica/cadastra
→ fotografa
→ IA auxilia conteúdo
→ estoque recebe
→ etiqueta
→ publica nos canais
→ vende
→ estoque baixa
→ comissão/caixa atualizam
→ analytics aprende com dados reais
```

## Público-alvo inicial

Varejo de moda e categorias adjacentes, especialmente operações com variantes (cor/tamanho/modelo), múltiplas lojas e venda omnichannel. A arquitetura deve permanecer suficientemente genérica para outros varejos sem sacrificar a profundidade de moda.

## Princípios de produto

- cadastrar uma vez, reutilizar em todos os canais;
- mobile como ferramenta operacional, não apenas dashboard reduzido;
- site próprio integrado nativamente;
- dados reais antes de IA;
- automação com checkpoint humano onde houver risco;
- simplicidade de onboarding;
- exportabilidade e integração;
- SaaS seguro e multi-tenant;
- moda-first, mas não fashion-only.

## Não objetivos iniciais

Não construir simultaneamente banco, PDV, fiscal próprio, marketplace hub completo, IA generativa, site builder e billing SaaS. O roadmap é incremental e deve validar valor em operação real antes de ampliar superfície.
