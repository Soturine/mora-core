# Personas e Jornadas Críticas

## Proprietário
Quer visão consolidada, estoque, vendas, caixa, comissões, alertas e comparação entre lojas/canais.

## Gerente
Opera catálogo, estoque, equipe, autorizações, fechamento e publicação.

## Vendedor
Login individual, consulta produto/estoque, realiza/atribui venda e acompanha comissão permitida.

## Caixa
Abre/fecha caixa, recebe pagamentos e reconcilia movimentos conforme permissão.

## Estoquista
Recebe mercadoria, cadastra/escaneia, inventaria, ajusta e transfere.

## Contador
Acesso restrito a relatórios/documentos relevantes, sem privilégios operacionais desnecessários.

## Merchant SaaS
Configura organização, lojas, equipe, catálogo, site, canais, importação e assinatura.

## Jornadas críticas

### Recebimento pelo celular
Escanear fabricante ou gerar código interno → criar/selecionar produto → variantes → quantidade/custo/preço → fotos → salvar → entrada de estoque → opcional aprovação/publicação.

### Venda física
Login → selecionar vendedor → itens/variantes → pagamento → finalizar → movimentação de estoque → comissão provisionada → caixa atualizado → audit.

### Fechamento de caixa
Abrir sessão → registrar movimentos → contar dinheiro/reconciliar meios → detectar divergência → motivo/aprovação → fechar.

### Fechamento mensal de comissão
Consolidar entries elegíveis → aplicar reversões → gerar statement → revisar → fechar/pagar.

### Publicar em canais
Produto canônico → validar dados/mídia por canal → criar listing → registrar external IDs → monitorar sync/errors.

### Inventário offline
Selecionar local → escanear/contar → persistir localmente → sync idempotente → revisar divergências → aprovar ajuste.
