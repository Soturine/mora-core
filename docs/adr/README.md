# Architecture Decision Records (ADRs)

ADRs registram decisões estruturais para impedir que futuras sessões/agentes redescubram e contradigam decisões sem contexto.

## Formato

`NNNN-titulo.md`

Seções: Status, Contexto, Alternativas, Decisão, Consequências, Evidências/Links.
