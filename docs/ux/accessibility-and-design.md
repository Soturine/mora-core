# UX, Design System e Acessibilidade

## Princípio

O Mora Core deve parecer ferramenta de varejo, não template genérico de SaaS.

## Acessibilidade

Semântica HTML, teclado, foco visível, labels, mensagens de erro, contraste, leitores de tela, browser zoom, reduced motion e touch targets adequados são requisitos desde o componente.

## Mobile first operacional

Scanner, inventário, cadastro e recebimento precisam funcionar com uma mão, iluminação variável e conexão ruim. Ações destrutivas/sensíveis exigem confirmação proporcional e feedback inequívoco.

## Estado

Distinguir server state, form state, URL state, UI state e preferências persistentes. Não colocar tudo em store global.

## Permissões

UI pode esconder ação não autorizada, mas backend continua autoridade. Interfaces devem deixar claro quando usuário está em outra organização/loja.

## Dashboards

Priorizar decisão operacional: estoque baixo, vendas, caixa, divergências e tarefas pendentes. Evitar vanity metrics.

## Storefront

Design por tokens/componentes seguros, responsividade real, SEO, performance, imagens otimizadas e páginas de produto acessíveis.
